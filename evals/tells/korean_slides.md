## 1차 평가 결과 : 기존 지표 기반 비교

- **목적** : 후보 모델 3종의 예측 성능을 기존 지표로 비교함
- **방법** : 동일 학습 자료로 학습 후 시험 자료에서 오차 측정
- **적용 대상** : 회귀 모델 · 결정나무 모델 · 신경망 모델
- **평가 데이터** : 2023–2025년 판매 기록 1,200건
- **평가 방법** : 평균 절대 백분율 오차(MAPE), 기존 방식 대비
- **결과** : 신경망 모델 오차 9%로 기존 18% 대비 절반 수준

> 결론 : 신경망 모델을 2차 평가 대상으로 선정함

## 2차 평가 : 계절 구간별 비교

- **목적** : 1차의 한계를 보완해 계절 구간별 성능을 확인함
- **방법** : 계절 4구간으로 나누어 같은 지표로 비교
- **결과** : 4구간 중 3구간에서 1위, 겨울 구간은 2위

> 결론 : 겨울 구간 보정이 다음 과제임
