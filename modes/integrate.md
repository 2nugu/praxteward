# Integrate

Goal: one coherent, verified deliverable from several units or delegate results.

- G1. Collect every unit's output. Review delegated output yourself: read the diff or text and check its evidence.
- G2. Check each unit against the check written in the plan; send failing units back to Execute.
- G3. Merge: resolve conflicts in terminology, numbers, interfaces, style, and claims. Use one name per concept.
- G4. Review the affected flow, including connected artifacts outside the diff, against the goal and actual usage. Confirm replacements retired obsolete paths and required growth has a reason under craft's Code rules. Each finding needs a concrete failure or unmet criterion, consequence, locator, and adequate correction. State consequential assumptions; rank correctness and integrity before economy. Flag unrelated cleanup; hypothetical scale and style preferences are not defects.
- G5. Verify end to end: run the full flow, read the document through, render the slides or figures, re-run the analysis. Run the [output checks](../references/output.md) (gates fixed, signals judged) and the generic-feel review in [craft](../references/craft.md).
- G6. Deliver: lead with the result, separate done from proposed, list unknowns. When continuity applies, update records and the recovery summary, increment the task-type tally, and add an episode line if a signal fired (SKILL.md Practice).
