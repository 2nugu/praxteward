# Integrate

Goal: one coherent, verified deliverable from several units or delegate results.

- G1. Collect every unit's output. Review delegated output yourself: read the diff or text and check its evidence.
- G2. Check each unit against the check written in the plan; send failing units back to Execute.
- G3. Merge: resolve conflicts in terminology, numbers, interfaces, style, and claims. Use one name per concept.
- G4. Check the whole against the frame: is the goal met for its audience, what is missing, what goes beyond scope (remove it or flag it).
- G5. Verify end to end: run the full flow, read the document through, render the slides or figures, re-run the analysis. Run the generic-feel review in [craft](../references/craft.md) and pass the output checks.
- G6. Deliver: lead with the result, separate done from proposed, list unknowns. When continuity applies, update records and the recovery summary, increment the task-type tally, and add an episode line if a signal fired (SKILL.md Practice).
